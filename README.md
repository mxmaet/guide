# Introduction

Cette section liste **factuellement** des événements, décisions et données qui démontrent :

* La **trahison des élites** françaises
* L'**abandon de souveraineté** économique, industrielle et militaire
* Les **décisions contraires** aux intérêts nationaux
* Les **conflits d'intérêts** et collusions

**Objectif :** Documenter avec sources les faits. Laisser les lecteurs tirer leurs conclusions.
